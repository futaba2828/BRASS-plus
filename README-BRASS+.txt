BRASS+ 修正版ファイル

同梱ファイル
- index.html : アプリ画面
- server.js : 共有グループAPI、同期、課題点分析API
- package.json : Render用設定

大切な注意
- /api/analyze は現在、タグの件数と練習ヒントを使うルールベース分析です。生成AIではありません。
- Renderの無料サービスは、保存したJSONファイルが再起動・再デプロイで消える場合があります。共有データを長く保存するにはRenderのPersistent Diskか外部DBの設定が必要です。
- この段階では共有グループのコードを知っている人が参加できる設計です。URLを知っている人だけに限定するログイン認証はまだありません。
- グループコードは大文字小文字を区別しない扱いです。重複コードは「すでに存在しています」と表示します。

更新前に、今のGitHubリポジトリのファイルをバックアップしてください。
index.html.txt ではなく、リポジトリの index.html をこの index.html で置き換え、server.js と package.json も同梱版で置き換えます。
