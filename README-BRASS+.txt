BRASS+ 修正版：これまでの依頼をまとめたZIP

同梱ファイル
- index.html：音符アイコン、選択テーマカラーの反映、既存の画面・記録機能、更新ボタン、共有同期。レッスンの振り返りカードも左スワイプで編集・削除できます。
- server.js：参加コード別の共有グループAPIと同期機能
- package.json：Render起動設定

グループ同期
- LINE内ブラウザでも、iPhoneホーム画面に追加したBRASS+でも、同じ参加コードのグループに参加してください。招待URLは使いません。
- 同じグループの「共有」データはサーバーを通じて同期します。「自分だけ」の項目は共有しません。
- 上部の「↻ 更新」でサーバーから最新の共有データを取り直せます。
- 同期には、このZIP内の index.html と server.js を両方デプロイする必要があります。

公開方法
1. ZIPを解凍します。
2. GitHubプロジェクトの index.html、server.js、package.json を同梱ファイルで置き換えます。
3. GitHubへ反映し、Renderのデプロイ完了後に確認します。
4. iPhoneのホーム画面アイコンはiOSにキャッシュされることがあり、テーマ色が即時反映されない場合は、ホーム画面アイコンの削除・再追加が必要になることがあります。

重要な注意
- このZIPを作成しただけでは、公開中のサイトは更新されません。
- 同じ参加コードを知っている人は参加できる設計で、ログイン認証はありません。
- RenderのローカルJSON保存は再起動・再デプロイで失われる場合があります。長期保存には永続ディスクまたは外部DBが必要です。
- デプロイ前に既存ファイルをバックアップしてください。


【今回追加】
・グループ管理の各グループに「一覧から削除」を追加。サーバーに存在しない古いグループも、この端末の一覧から削除できます。
・「一覧から削除」は端末内の登録だけを外し、サーバー上のグループや他のメンバーのデータは削除しません。「退会」とは別の操作です。
・iPhoneのホーム画面アイコンは、テーマカラー変更後にiOS側で古い画像がキャッシュされることがあります。色変更後はホーム画面の旧アイコンを削除し、Safariから「ホーム画面に追加」をやり直してください。iOSの仕様により、既存アイコンをコードから即時変更することは保証できません。


重要：iPhoneのホーム画面アイコンはiOS側にキャッシュされるため、テーマカラー変更だけで既存アイコンが即時変更される保証はありません。変更を反映したい場合は、ホーム画面から既存アイコンを削除し、Safariでサイトを開いて「ホーム画面に追加」をやり直してください。これはWebアプリ側だけでは強制更新できないiOSの制約です。

同じ参加コードについて：サーバー上に既に存在するコードを「グループを作成」側に入力した場合も、エラーで止まらず既存グループへの参加として処理します。「このコードのグループに参加」からの参加も引き続き使えます。


【アイコン修正】
テーマカラー変更時のアイコン生成処理は、以前色が反映されていた版の処理に戻しました。iPhoneホーム画面で古いアイコンが残る場合は、古いアイコンを削除してからSafariで追加し直してください。
