BRASS+ 完成版（共有サーバー対応）

同梱ファイル
- index.html : アプリ画面。テーマ色に合わせてブラウザアイコン用画像を生成する処理を追加
- server.js : 共有グループAPI、同期、課題点分析API
- package.json : Render用起動設定
- README-BRASS+.txt : この説明

使い方
1. ZIPを解凍し、4ファイルを同じプロジェクトフォルダに置きます。
2. GitHubリポジトリを更新するときは、先に既存ファイルをバックアップしてください。
3. index.html、server.js、package.json をリポジトリ内の同名ファイルと置き換えます。
4. RenderがGitHub連携で自動デプロイする設定なら、デプロイ完了後にサイトを再読み込みして確認します。

注意
- このZIPを作っただけでは、公開中のサイトやGitHubは更新されません。ファイルをリポジトリへ反映する作業が必要です。
- iPhoneのホーム画面アイコンはiOS側でキャッシュされるため、テーマ色変更に合わせて既に追加済みのアイコンが必ず即時更新されるとは限りません。Safariのタブアイコンとブラウザのテーマ色には反映するようにしています。
- /api/analyze はタグ件数や練習ヒントを使うルールベース分析で、生成AIではありません。
- Render無料サービスのローカルJSON保存は、再起動・再デプロイで消える場合があります。長期保存にはPersistent Diskまたは外部DBの設定が必要です。
- グループコードを知っている人が参加できる設計です。URLを知っている人だけに限定するログイン認証はまだありません。
- 既存のGitHub/Renderファイルは、更新前に必ずバックアップしてください。


【リアルタイム通知・グループ管理の改善】
・共有項目の登録/変更とメンバーの参加/退会を、約2秒間隔でサーバーに確認して通知します。通常は数秒以内に反映されますが、厳密な即時配信（WebSocket/SSE）ではありません。
・グループ管理画面を、作成・招待コードで参加・参加中グループの切替/退会が分かる形に整理しました。
・このZIPを使うには、index.html と server.js と package.json を一緒に更新し、Renderで再デプロイする必要があります。ZIPをダウンロードしただけでは公開サイトは変わりません。
