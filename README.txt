BRASS+ 更新ファイル

含まれるファイル:
- index.html: アプリ画面
- server.js: 共有グループ・同期サーバー
- package.json: Render等での起動設定

今回の変更:
- 音階リストの名称を「音階」に変更
- 長音階の H を B に変更
- 長音階の上に「長音階」、短音階の上に「短音階」を小さく表示
- B♭m〜B♭m(8va) の短音階リストを追加
- グループ参加画面から招待URL機能を外し、コード入力を使用
- 名前変更時は端末IDを使って既存メンバー名を更新
- 練習・課題点の共有削除をサーバーに反映
- 朝練の記録はグループ共有対象から除外（朝練王の端末内の集計表示は残す）
