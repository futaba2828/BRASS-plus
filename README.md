# BRASS+ 完全版（サーバー共有対応）

## できること
- BRASS+の既存機能をそのまま利用
- 「記録」タブのタップを安定化
- タブ長押し→左右スワイプで並べ替え
- 設定（右上の歯車）からタブの並べ替え・表示設定
- グループ作成／グループコードで参加
- 「グループで共有」にしたデータをサーバーへ同期
- 同じグループのメンバーの共有データを取得
- ローカルデータはlocalStorage/IndexedDBにも保存

## 起動
Node.jsをインストールしたPCで、このフォルダを開いて

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開きます。

## グループ共有
1. 右上の歯車 → プロフィール・設定
2. 共有グループの「新しいグループを作る」
3. 表示された6文字のグループコードを友達に渡す
4. 友達は同じBRASS+サーバーURLとコードを入力して「コードで参加」
5. 目標・練習・課題点などの登録時に「グループで共有」を選ぶ

## 注意
この版は学校内など小規模な共有を想定した試作サーバーです。ログイン認証、権限管理、暗号化、ファイルストレージ、削除同期などは本番運用前に追加してください。
